# Figma フレーム整理ガイド

Cursor が Figma MCP でデザインを読むとき、**フレームの名前と入れ子がそのまま手がかり**になる。
自動レイアウトを細かく組む必要はないが、以下だけ揃えておくと実装の精度が大きく上がる。

## 1. ページとフレームの単位

- Figma のページは「サイト」用に1つでよい（例: `Site`）。
- サイトの1ページにつき、PCとSPのトップレベルフレームを1つずつ作る。

| フレーム名 | 幅   | 中身                 |
| ---------- | ---- | -------------------- |
| `top/pc`   | 1440 | トップページ PC 全体 |
| `top/sp`   | 375  | トップページ SP 全体 |
| `about/pc` | 1440 | 学校について PC      |
| `about/sp` | 375  | 学校について SP      |

- 名前の前半（`top`, `about` など）は**そのままURLのスラッグ**になる（`about/index.html`）。英小文字・ハイフンで付ける。
- SPデザインがまだないページは `pc` だけでよい。SPは Cursor が DESIGN_RULES.md のSP値で組む。

## 2. セクションは直下の子フレームにする

ページのフレームの直下に、セクションごとのフレーム（またはグループ）を上から順に並べる。

```
top/pc
├─ header
├─ hero
├─ marquee
├─ about
├─ learn
├─ life
├─ open-campus
└─ footer
```

- 名前はコードのクラス名になる（`hero` → `.p-top-hero`）。英小文字・ハイフンで付ける。
- ヘッダー・フッターなど**全ページ共通のもの**は、どのページでも同じ名前（`header`, `footer`）にする。
- PCとSPで同じセクションは同じ名前にする（`top/pc` の `about` と `top/sp` の `about`）。

## 3. 中身で気をつけること（最低限）

- **文字はテキストレイヤーのまま**にする（アウトライン化しない）。
- **写真は1枚ずつ独立したレイヤー**にする。切り抜き・トリミングは画像の塗りかマスクで。文字と写真を結合しない。
- 写真レイヤーに書き出し設定（WebP か PNG、2x）を付けておくと、Cursor が素材を取り出しやすい。
- 繰り返す部品（ボタン、カード、セクション見出し）は、できればコンポーネント化する。無理なら同じ見た目に揃えるだけでよい。
- 使っていない検討用レイヤー・非表示レイヤーは、ページのフレームの外へ出すか削除する（Cursor が拾ってしまうため）。

## 4. 整理が終わったら

`top/pc` を選んで「リンクをコピー」し、そのURLを Cursor に渡す（docs/CODING_PLAN.md の STEP 0）。
Cursor がフレーム一覧を読み取り、各セクションのノードIDを docs/PROGRESS.md に書き込む。
