# デザインルール

Figma は見た目の正本、このファイルは**数値の正本**。
Figma の数値は下のトークンへ丸めて実装する（4px以下のズレは誤差として扱う）。
SCSS での実体は `src/scss/foundation/_tokens.scss`。

デザインの方向は「ピンク基調・切り貼りのコラージュ・人物写真」。
白フチの写真を少し傾けて貼り、マスキングテープ・手描きのイラスト・蛍光ペンの線を重ねて、雑誌のスクラップのような楽しさを出す。
文字は Noto Sans JP の太字でくっきり組み、強調はピンクで入れる。

## 1. 画面幅

| 名前         | 幅       | 用途                                                       |
| ------------ | -------- | ---------------------------------------------------------- |
| SP基準幅     | 375px    | SPデザインはないが、`fluid()` の最小値はこの幅での値とする |
| `md`         | 768px〜  | タブレット。2カラムを解禁してよい                          |
| `lg`         | 1024px〜 | PCレイアウト（ヘッダーのナビ表示など）                     |
| PCデザイン幅 | 1440px   | PCの基準。`fluid()` の最大値はこの幅での値                 |

- 書き方はモバイルファースト（SPを素で書き、`@include mq(lg)` で上書き）。
- 375〜1440px の間は `fluid(SP値, PC値)` で連続的に変える。1440px 超は最大値で止まり、コンテンツ幅 1312px で中央寄せ。
- 左右の余白（ガター）は `var(--gutter)`（SP 20px → PC 64px）。Figma の TOP/PC も左右 64px・中身 1312px で組まれている。
- 背景色の付いた帯（ロードマップの白、学費・説明会の淡ピンク、フッター）は画面幅いっぱいに敷き、中身だけ `.l-container` に入れる。

## 3. フォントと文字の役割

書体は3つだけ使う。

- **Noto Sans JP**（400 / 500 / 700 / 800 / 900）… 日本語すべて。見出しは 700、強い一語は 900
- **Noto Sans**（700、イタリックあり）… 英字ラベル（CONCEPT、01 / LEARN）とロードマップの年数
- **Georgia**（太字イタリック、端末のフォント）… 大きな番号（01〜05、「5つの特長」の 5）

手書き風の英字（「Learn & Work」「Let's talk!」）と、ヒーローのキャッチコピーは画像素材。HTML 側には同じ文言をテキストで持たせる（§8）。

- ロードマップ卒業帯の「美容師免許取得」は、ゴールを強調するため24 → 36px（700・行間1.1）とする（ユーザー承認済み）。左の「卒業」ラベルは20 → 30pxのまま。
- ロードマップの卒業バー左側の「卒業」は Figma 上 32px だが、上表の**強調の一文（PC 30px）**に丸めて使う。
- 改行位置は `<br>` で固定しすぎない。崩したくない語句は `.u-nowrap` で包む。
- ナビは SP では全画面メニューの中に入るので、PCより大きい 16px にする。

## 4. 余白

8px基準のスケール `space(1〜12)` = 4 / 8 / 12 / 16 / 24 / 32 / 40 / 48 / 64 / 80 / 96 / 120 px。
Figma の 10・20・22・36px は、それぞれ 8・24・24・40 ではなく**近い方**（12・24・24・32〜40）へ丸める。

| 場所                                      | 値                                                     |
| ----------------------------------------- | ------------------------------------------------------ |
| セクション上下                            | `.l-section` = `fluid(64, 120)`                        |
| 背景色のある帯の内側の上下                | `fluid(56, 80)`                                        |
| 英字ラベル → 見出し                       | `space(5)` 24px                                        |
| 見出しブロック → 本文・カード群           | `fluid(32, 56)`                                        |
| 番号 → 見出し → 横線 → 本文（特長カード） | 番号と見出しは 0〜`space(2)`、見出し → 本文 `space(4)` |
| 本文の段落間                              | `space(5)` 24px                                        |
| カード同士（3列）                         | SP `space(8)` 縦積み / PC `space(6)` 32px              |
| ロゴ枠同士                                | `space(4)` 16px                                        |
| ボタン同士                                | `space(4)` 16px                                        |

## 5. 角丸と形

| トークン | 値    | 使いどころ                                   |
| -------- | ----- | -------------------------------------------- |
| `none`   | 0     | 写真、ロゴ枠、カード（角丸にしない）         |
| `sm`     | 8px   | 卒業バーのような横長の小さな面               |
| `pill`   | 999px | ボタン、タグ（オンライン・来校）、丸アイコン |

- **角を斜めに切り落としたカード**（学費・説明会のカード、ロードマップの3枚）は、`clip-path: polygon()` で作る。左上と右下の角を切り、切り落とす幅はカードの短辺のおよそ 1/4〜1/3（Figma のノードで測る）。
- 切り落としカードの後ろに、少しずらしたピンクの面を敷くことがある（学費・説明会）。これも `clip-path` か `::before` で作る。

## 6. ボタン

| 種類       | 見た目                                                                 | 用途                                         |
| ---------- | ---------------------------------------------------------------------- | -------------------------------------------- |
| プライマリ | pink 背景・白文字・白い枠 2〜3px の外側に pink の細い輪・右に「>」矢印 | 説明会・入学相談、説明会に申し込む           |
| セカンダリ | 白背景・pink 文字・pink の枠 2px・右に「>」矢印                        | 資料請求、学費の詳細を見る                   |
| 一覧の矢印 | 文字の右に細い「→」                                                    | 一覧行向け（旧お知らせセクションは削除済み） |
| 丸ボタン   | pink の丸（36px）に白い「＋」                                          | 開閉など補助の操作                           |

| サイズ | 高さ      | 文字           | 使う場所                             |
| ------ | --------- | -------------- | ------------------------------------ |
| L      | 64 → 75px | 18 → 24px・700 | カードの下の主ボタン（横幅いっぱい） |
| M      | 56 → 64px | 18 → 20px・800 | ヒーロー                             |
| S      | 42px      | 12px・800      | ヘッダー                             |

- フッターCTAのみFigma準拠の例外（2026-11-13ユーザー承認）: 説明会は白い切り落とし、資料請求は透明背景＋白枠・角丸8px。`c-button` のフッター専用modifierで表現する。
- その他の形はすべて `pill`。最小タップ領域 44px（S もタップ領域は 44px 確保する）。
- 主導線（説明会・入学相談）と第二導線（資料請求）は、並べるときは必ずこの順。
- SPでは CTA エリアのボタンを全幅・縦積みにしてよい。

- お問い合わせフォームの送信ボタンは、STEP 16のユーザー承認によりFigmaの灰色・小さい角丸（`radius(sm)`）を採用する。入力確認時も送信先は未接続。文字コントラストを保つため有効時の灰色は `gray` を使う。

## 7. 写真・装飾

- **写真の貼り方**: 白フチ（10〜12px）＋ 影 `$shadow-photo`、−4°〜＋7° 程度傾ける。セクションの主役の写真だけに使い、1セクション1〜2枚まで。
- 傾けない写真（特長カードの写真など）は、白フチなし・角丸なしで四角く使う。
- 写真の後ろに、少しずらした pink の面（平行四辺形）を敷いてよい。
- **マスキングテープ**: `tape` 色の 100×24px の帯を写真の角に斜めに貼る。1セクション1〜2枚まで。
- **蛍光ペンの線**: 見出しの強調語の下に、黄色の手描きの線（画像素材）を敷く。
- **手描きイラスト**: ピンクの線画（ハサミ、くし、本、鏡など）。画像素材として書き出し、見出しやカードの余白に添える。装飾なので `alt=""`。
- 切り抜き人物は、ヒーローのように写真の上へ大きく重ねて使う。
- 動きは控えめにする（ふわっと出る、写真が少し回転するなど）。スクロール連動の演出は 0.4〜0.8s、`$ease-out`。

## 8. コピーの扱い

- 学校名は「学校名」。未確定情報は `[日付]` `[時間]` `[金額]` `[所在地]` のように角括弧で残す。
- 実績・数字・在校生の声など、根拠のない事実を書き足さない。「説明文が入ります。」のようなダミー文は、そのまま残すか、ユーザーに確認する。
- ヒーローのキャッチ「働きながら、」「免許も。」「学びと現場経験を重ねる、3年間。」は画像素材。`<h1>` には同じ文言をテキストで入れ、画像は `alt=""` にする（読み上げが二重にならないように）。
- 手書き風の英字（Learn & Work など）は飾りなので `alt=""`。
- 写真がイメージ（仮素材）である旨の注記は、写真を多用するセクションの下に小さく入れる。

## 9. SP・タブレットの組み方（SPデザインがない前提）

Figma にあるのは PC（1440px）のデザインだけ。SP・タブレットはこの章のルールで Cursor が組み直す。
**PCをそのまま縮小しない**。同じ内容を、狭い画面で読みやすい順番と大きさに並べ直す。

### 9-1. 共通ルール（全ページ）

| 項目               | ルール                                                                                                                                            |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 並び順             | HTMLの順番 ＝ SPの縦の並び順。PCで左右に並ぶブロックは、SPでは「見出し → 写真 → 本文 → ボタン」の順に縦積みにする                                 |
| カラム数           | PC 3〜4列 → タブレット（`md`）2列 → SP 1列。写真だけのタイルはSPでも2列にしてよい                                                                 |
| 余白               | 左右はガター（SP 20px）。セクション上下・要素間は `fluid()` でSP値まで自然に縮む                                                                  |
| 文字               | §3 の役割表のSP値を使う。本文はSPでも 15px より小さくしない                                                                                       |
| 改行               | PC用の `<br>` がSPで不自然なら、`<br class="u-pc-only">` にするか、語句を `.u-nowrap` で包む。1文字だけの行（「に。」など）を作らない             |
| 写真               | SPでは画面幅いっぱい、またはガター内の幅。横長の写真はSPで 4:3 などの縦寄りの比率に `aspect-ratio` で切り直し、`object-position` で顔や主題を残す |
| 切り抜き人物       | SPでは画面幅の 85〜90% 程度の大きさにする                                                                                                         |
| 重なり演出         | 写真の傾き・テープ・イラストの重なりはSPでも残してよいが、量を減らし、重なりを浅くする。**本文や日本語の見出しには何も重ねない**                  |
| 装飾               | SPでは数を減らす。イラストは1セクション1つまで、テープは1枚まで。小さくしても形がわからないものは非表示                                           |
| 切り落としカード   | SPでも形は残す。切り落とす幅はカードの大きさに合わせて小さくする                                                                                  |
| ナビ               | `lg` 未満はヘッダーにロゴ＋メニューボタン。ナビとヘッダーのCTAは全画面メニューの中に入れる                                                        |
| ボタン             | CTAが2つ並ぶ場所は、SPでは全幅の縦積み（主導線を上）                                                                                              |
| カードが多いリスト | 基本は1列の縦積み。6枚を超えて縦に長くなりすぎる場合だけ、横スワイプ（`scroll-snap`）を提案してから使う                                           |
| 表                 | `overflow-x: auto` の箱に入れて横スクロールさせる                                                                                                 |
| ホバー演出         | SPでは発生しない前提で、ホバーがなくても情報が欠けないようにする                                                                                  |
| 確認する幅         | 375 / 390 / 430 / 768 / 1024 / 1440                                                                                                               |
