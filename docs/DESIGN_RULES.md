# デザインルール

Figma は見た目の正本、このファイルは**数値の正本**。
Figma の数値は下のトークンへ丸めて実装する（4px以下のズレは誤差として扱う）。
SCSS での実体は `src/scss/foundation/_tokens.scss`。

## 1. 画面幅

| 名前         | 幅       | 用途                                       |
| ------------ | -------- | ------------------------------------------ |
| SPデザイン幅 | 375px    | SPの基準。`fluid()` の最小値はこの幅での値 |
| `md`         | 768px〜  | タブレット。2カラムを解禁してよい          |
| `lg`         | 1024px〜 | PCレイアウト（ヘッダーのナビ表示など）     |
| PCデザイン幅 | 1440px   | PCの基準。`fluid()` の最大値はこの幅での値 |

- 書き方はモバイルファースト（SPを素で書き、`@include mq(lg)` で上書き）。
- 375〜1440px の間は `fluid(SP値, PC値)` で連続的に変える。1440px 超は最大値で止まり、コンテンツ幅 1280px で中央寄せ。
- 左右の余白（ガター）は `var(--gutter)`（SP 20px → PC 64px）。

## 2. カラー

| トークン                     | 値      | 使いどころ                                                                     |
| ---------------------------- | ------- | ------------------------------------------------------------------------------ |
| `paper`                      | #F5F1EA | 基本の背景                                                                     |
| `ink`                        | #161216 | 文字、黒背景セクション、メインボタン                                           |
| `pink`                       | #FF2E7E | メインアクセント。鏡モチーフ、強調、OCセクション背景                           |
| `lime`                       | #D8FF3C | サブアクセント。ボタンの矢印丸、ラベル、マーカー。**白背景の文字には使わない** |
| `lilac` / `beige` / `orange` | —       | カラーチャートの毛束、カード背景などの補助                                     |
| `white`                      | #FFF    | ピンク・黒の上の文字                                                           |
| `muted`                      | #4A4148 | 補足テキスト                                                                   |

- 本文テキストのコントラストは 4.5:1 以上。ピンク背景に白文字は**24px以上の大きな文字だけ**。
- グラデーション背景は使わない（マーカー線など細部を除く）。

| セクション英字見出し     | Instrument Serif            | 56 → 128  | 0.92 | -0.02em |
| h1（日本語キャッチ）     | Shippori Mincho 800         | 32 → 60   | 1.35 | 0.04em  |
| h2（日本語見出し）       | Shippori Mincho 800         | 36 → 76   | 1.3  | 0.04em  |
| ステートメント           | Shippori Mincho 600         | 26 → 60   | 1.75 | 0.04em  |
| h3（カード見出し・英）   | Instrument Serif イタリック | 40 → 56   | 1.0  | 0       |
| h3（カード見出し・日）   | Noto Sans JP 900            | 18 → 18   | 1.5  | 0.04em  |
| リード                   | Shippori Mincho 800         | 22 → 34   | 1.6  | 0.04em  |
| 本文                     | Noto Sans JP 400            | 15 → 15   | 2.0  | 0.06em  |
| 小さい本文               | Noto Sans JP 400            | 13 → 14   | 1.9  | 0.06em  |
| キャプション・注記       | Noto Sans JP 400            | 11 → 12   | 1.6  | 0.06em  |

- 日本語の見出しは明朝、本文・UIはゴシック、英字の装飾はセリフかAnton。この4書体以外は使わない。
- 改行位置は `<br>` で固定しすぎない。崩したくない語句は `.u-nowrap` で包む。

## 4. 余白

8px基準のスケール `space(1〜13)` = 4 / 8 / 12 / 16 / 24 / 32 / 40 / 48 / 64 / 80 / 96 / 128 / 160 px。

| 場所                            | 値                                                |
| ------------------------------- | ------------------------------------------------- |
| セクション上下                  | `.l-section` = `fluid(80, 160)`                   |
| 英字ラベル → 見出し             | `space(4)` 16px                                   |
| 見出しブロック → 本文・カード群 | `fluid(40, 64)`                                   |
| 本文の段落間                    | `space(5)` 24px                                   |
| カード・タイル同士              | `space(4)` 16px（PCのカラム間は `space(6)` 32px） |
| カード内の要素間                | `space(2)`〜`space(4)`                            |
| ボタン同士                      | `space(3)` 12px                                   |

## 5. 角丸

| トークン | 値    | 使いどころ                     |
| -------- | ----- | ------------------------------ |
| `sm`     | 12px  | ラベル、小さなタグ             |
| `md`     | 20px  | 日程カードなど中くらいのカード |
| `lg`     | 24px  | 写真タイル                     |
| `pill`   | 999px | ボタン、ナビ、タグ             |

## 6. ボタン

| 種類           | 見た目                                      | 用途                                             |
| -------------- | ------------------------------------------- | ------------------------------------------------ |
| プライマリ     | ink 背景・白文字・右に lime の丸＋矢印      | オープンキャンパス予約など主導線。1画面に1つまで |
| セカンダリ     | 枠線 1.5px ink（濃い背景上では paper 背景） | 資料請求など第二導線                             |
| テキストリンク | 文字＋枠線の丸矢印                          | 「学校について」などセクション内の詳細リンク     |

- 高さ: L 64px（SP 60px）/ M 48px。最小タップ領域 44px。
- SPでは CTA エリアのボタンを全幅・縦積みにしてよい。

## 7. 写真・装飾

- 写真は角丸 `lg` か、切り抜き（透過）で使う。枠線やドロップシャドウは付けない。
- 鏡（円）モチーフは各ページ1〜2か所まで。
- 手描き風の装飾（スパークル、矢印）は1セクションに1つまで。
- 動き: マーキー、回転バッジ程度。スクロール連動の演出は 0.4〜0.8s、`$ease-out`。

## 8. コピーの扱い

- 学校名は「学校名」。未確定情報は `[日付]` `[時間]` `[会場]` `[所在地]` のように角括弧で残す。
- 実績・数字・在校生の声など、根拠のない事実を書き足さない。
- 写真がイメージ（仮素材）である旨の注記は、写真を多用するセクションの下に小さく入れる。

## 9. SP・タブレットの組み方（SPデザインがない前提）

Figma にあるのは PC（1440px）のデザインだけ。SP・タブレットはこの章のルールで Cursor が組み直す。
**PCをそのまま縮小しない**。同じ内容を、狭い画面で読みやすい順番と大きさに並べ直す。

参考: [docs/reference/prototype/index.html](reference/prototype/index.html) は幅に応じて組み替わる初期プロトタイプ。ブラウザの幅を 375px にすると、この章の考え方で組んだSPの例が見られる（見た目の細部は Figma 優先）。

### 9-1. 共通ルール（全ページ）

| 項目               | ルール                                                                                                                                            |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 並び順             | HTMLの順番 ＝ SPの縦の並び順。PCで左右に並ぶブロックは、SPでは「見出し → 写真 → 本文 → ボタン」の順に縦積みにする                                 |
| カラム数           | PC 3〜4列 → タブレット（`md`）2列 → SP 1列。写真だけのタイルはSPでも2列にしてよい                                                                 |
| 余白               | 左右はガター（SP 20px）。セクション上下・要素間は `fluid()` でSP値まで自然に縮む                                                                  |
| 文字               | §3 の役割表のSP値を使う。本文はSPでも 15px のまま小さくしない                                                                                     |
| 改行               | PC用の `<br>` がSPで不自然なら、`<br class="u-pc-only">` にするか、語句を `.u-nowrap` で包む。1文字だけの行（「校。」など）を作らない             |
| 写真               | SPでは画面幅いっぱい、またはガター内の幅。横長の写真はSPで 4:5 などの縦寄りの比率に `aspect-ratio` で切り直し、`object-position` で顔や主題を残す |
| 切り抜き人物       | SPでは画面幅の 85〜90% 程度の大きさにする                                                                                                         |
| 重なり演出         | 写真と大きな英字の重なりはSPでも残してよいが、重なりを浅くする。**本文や日本語の見出しには何も重ねない**                                          |
| 装飾               | SPでは数を減らす。回転バッジ・スパークルは小さくするか1つに、縦書きラベルは非表示                                                                 |
| ナビ               | `lg` 未満はヘッダーにロゴ＋メニューボタン。ナビとヘッダーのCTAは全画面メニューの中に入れる                                                        |
| ボタン             | CTAが2つ並ぶ場所は、SPでは全幅の縦積み（主導線を上）                                                                                              |
| カードが多いリスト | 基本は1列の縦積み。6枚を超えて縦に長くなりすぎる場合だけ、横スワイプ（`scroll-snap`）を提案してから使う                                           |
| 表                 | `overflow-x: auto` の箱に入れて横スクロールさせる                                                                                                 |
| ホバー演出         | SPでは発生しない前提で、ホバーがなくても情報が欠けないようにする                                                                                  |
| 確認する幅         | 375 / 390 / 430 / 768 / 1024 / 1440                                                                                                               |

### 9-2. トップページの各セクション

| セクション  | SPでの組み方                                                                                                                                                                                          |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ヘッダー    | 高さ 64px。左にロゴ、右に丸いメニューボタン。オープンキャンパスのボタンはメニュー内とFVに置く                                                                                                         |
| FV          | 写真エリアの高さは 500px 前後。Self は左上、MADE. は右下で写真の下端に重ねる。鏡の円は画面幅の約75%。回転バッジは右上に小さく（96px）。キャッチ・補足・ボタンは写真エリアの下に縦積みし、ボタンは全幅 |
| マーキー    | 文字を 22px 程度に下げ、帯の高さは 52px                                                                                                                                                               |
| ABOUT       | ステートメントは 26px。文中の小さな写真はそのまま残す。本文とリンクは縦積み                                                                                                                           |
| LEARN       | 1列のリスト。毛束は 48×160px 程度に縮め、テキストと横並びのまま                                                                                                                                       |
| LIFE        | 2列グリッド。大きな写真は2列ぶち抜きで 4:5、残りのタイルは1:1                                                                                                                                         |
| OPEN CAMPUS | 英字見出しは 64px。日程カードは1列、ボタンは全幅の縦積み                                                                                                                                              |
| フッター    | ナビは2列、学校名のワードマークは画面幅に収まる大きさ（`19vw` 程度）                                                                                                                                  |
